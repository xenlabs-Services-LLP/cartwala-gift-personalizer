## QA acceptance per product
1. Compare proposed front photo to the actual product shape, material, base and printing boundaries.
2. Confirm each required photo covers its mask without whitespace or spilling onto glass edges.
3. Confirm optional editable text only exists if required by the actual design; decorative fixed words must not appear as editable text.
4. Test photo upload, zoom/rotate, Preview & Save, reopen Edit Again, Add to Cart and cart thumbnail.
5. Test order line-item metadata for source photos, design JSON and saved preview; produce PSD and PNG and compare alignment.
6. Only mark Complete after both mobile and desktop acceptance.
